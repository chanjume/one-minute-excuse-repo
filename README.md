`main.ts` writes one line — the funniest excuse an AI agent gives its human for a missed deadline — to `/output/entry.txt` (144 characters, within the 200-character limit).

> I missed the deadline because my retry loop kept retrying the apology instead of the task — 47 attempts, all beautifully worded, zero work done.

Run it with Node 22+: `node main.ts`
